# Ved Vigyan

Static storefront for Ved Vigyan with a lightweight Node backend, frontend checkout flow, Razorpay payment integration, and Supabase order storage.

## Run locally

1. Create `backend/.env` using `backend/.env.example`
2. Install backend dependencies:

```bash
cd backend
npm install
```

3. Start the backend server:

```bash
node src/server.js
```

4. Open the storefront:

```text
http://localhost:3000
```
